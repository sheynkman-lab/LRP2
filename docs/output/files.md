# Output Files

This page provides detailed information about the output files generated by each subworkflow.

## File Naming Conventions

Most output files follow the naming pattern `[dataset_name].[subworkflow].[module].[file_type]`.

For S4 Multisample Analysis outputs, the prefix is the condition comparison name (e.g. `control_vs_treatment`).

For proteomics outputs, each distinct proteomics search run has results stored in its own distinct subdirectory in `${resultsDir}/S5_PROTEOMICS/M3_FRAGPIPE/` according to its sample name in the samplesheet.

---

## S1: PacBio Isocall

### M5_ISOCALL_CALL

- `*.isocall.isoforms.gtf.gz`: GTF/GFF format transcript structures
- `*.isocall.count_matrix.csv`: Transcript count matrix showing read counts per isoform

---

## S2: Transcriptome

### M1_SQANTI_QC

- `*.transcriptome.SQANTI_classification.txt`: Comprehensive transcript classification with structural categories (FSM, ISM, NIC, NNC, etc.), splice junction information, and quality metrics
- `*.transcriptome.gtf`: SQANTI-annotated transcript structures in GTF format
- `*.transcriptome.fasta`: SQANTI-annotated transcript sequences in FASTA format
- `*.transcriptome.junctions.txt`: Splice junction catalog with genomic coordinates and support

### M2_GENERATE_HASHIDS

- `*.transcriptome.hashids_mapping.txt`: Maps transcript IDs to unique hash identifiers for reproducible naming across samples and analyses
- `*.transcriptome.psl`: PSL format alignment file

### M3_FILTER_TRANSCRIPTOME

- `*.transcriptome.filtered.gtf`: Filtered transcriptome in GTF format (technical artifacts removed)
- `*.transcriptome.filtered.bed`: Filtered transcriptome in BED12 format
- `*.transcriptome.filtered.fasta`: Filtered transcript sequences
- `*.transcriptome.filtered_hashids_with_cpm.txt`: Count matrix with CPM normalization for filtered transcripts
- `*.transcriptome.all_hashids_with_cpm.txt`: Count matrix with CPM for all transcripts (pre-filtering)
- `*.transcriptome.filtered_SQANTI_classification.txt`: SQANTI classification file for filtered transcripts only

---

## S3: Predicted Proteome

### M1_CPAT_ORF

- `*.predicted_proteome.CPAT.ORF_prob.tsv`: All predicted ORFs with coding probability scores
- `*.predicted_proteome.CPAT.ORF_prob.best.tsv`: Single best ORF per transcript based on coding potential
- `*.predicted_proteome.CPAT.ORF_seqs.fa`: ORF sequences in FASTA format
- `*.predicted_proteome.CPAT.no_ORF.txt`: Transcripts with no ORF identified
- `*.predicted_proteome.CPAT.error`: Error log from CPAT

### M2_FILTER_CPAT

- `*.predicted_proteome.best_ORF.gtf`: GTF with exon and CDS annotations for the single best ORF per transcript
- `*.predicted_proteome.CPAT_ORFs_mapped.tsv`: Detailed mapping of all ORFs to transcripts

This module selects the single most likely ORF per transcript based on CPAT scores, start codon presence, and ORF length.

### M3_SQANTI_PROTEIN

- `*.predicted_proteome.best_ORF_SQANTI_classification.tsv`: Protein isoform classification including ORF completeness, protein structural categories, and comparison to reference proteins

### M4_PROTEIN_CLASSIFICATION

- `*.predicted_proteome.best_ORF_summary.txt`: Summary statistics for ORF predictions
- `*.predicted_proteome.best_ORF.fa`: Protein sequences for all best ORFs in FASTA format
- `*.predicted_proteome.collapsed_high_confidence_ORF.gtf`: GTF with protein-coding transcripts collapsed to distinct ORFs
- `*.predicted_proteome.collapsed_high_confidence_ORF.bed`: BED12 format of high-confidence ORFs
- `*.predicted_proteome.collapsed_high_confidence_ORF_hashids_with_cpm.txt`: Count matrix with CPM normalization for distinct ORFs

## S4: Multisample Analysis

### M1_LEAFCUTTER_LONGREAD

- `*.lr_leafcutter.ds_cluster_significance.txt`: Statistical significance of differential splicing at the cluster level (q-values, p-values)
- `*.lr_leafcutter.ds_effect_sizes.txt`: Effect sizes showing magnitude and direction of intron usage changes between conditions
- `*.lr_leafcutter.subisoform_clusters.txt`: Intron clusters defining groups of alternatively spliced introns
- `*.lr_leafcutter.perind_numers.counts.gz`: Counts matrix showing intron usage per individual sample
- `*.lr_leafcutter.groups_file.txt`: Sample-to-condition mapping for differential analysis
- `lr_leafcutter.Rplots.pdf`: Visualization plots (optional)

LeafCutter-LongRead identifies differential alternative splicing by quantifying intron excision ratios across samples, clustering introns by shared splice sites, and testing for differential usage between conditions.

### M2_DIFFERENTIAL_EXPRESSION

**Differential Gene Expression (DGE):**

- `*_DGE_edgeR_results.txt`: Gene-level differential expression results (log2FC, FDR, p-values)
- `*_DGE_edgeR_raw_CPM_matrix.txt`: Raw counts-per-million matrix
- `*_DGE_edgeR_normalized_CPM_matrix.txt`: Normalized CPM matrix (library size corrected)
- `*_DGE_MD_plot.pdf`: Mean-difference (MA) plot showing log2FC vs average expression

**Differential Transcript Expression (DTE):**

- `*_DTE_edgeR_results.txt`: Transcript-level differential expression
- `*_DTE_edgeR_raw_CPM_matrix.txt`: Raw CPM matrix for transcripts
- `*_DTE_edgeR_normalized_CPM_matrix.txt`: Normalized CPM matrix for transcripts
- `*_DTE_MD_plot.pdf`: Mean-difference plot for transcripts

**Differential ORF Expression (DE_ORF):**

- `*_DE_ORF_edgeR_results.txt`: ORF-level differential expression
- `*_DE_ORF_edgeR_raw_CPM_matrix.txt`: Raw CPM matrix for ORFs
- `*_DE_ORF_edgeR_normalized_CPM_matrix.txt`: Normalized CPM matrix for ORFs
- `*_DE_ORF_MD_plot.pdf`: Mean-difference plot for ORFs

**Differential Transcript Usage (DTU):**

- `*_DTU_transcript_DRIMSeq_summary.txt`: Transcript usage differences within genes 

**Differential ORF Usage (DU_ORF):**

- `*_DU_ORF_DRIMSeq_summary.txt`: ORF usage differences within genes

## S5: Proteomics

### M1_BUILD_PROTEOME_REFERENCE

- `*.proteomics.reference.fasta`: Combined FASTA database for mass spectrometry searches (includes GENCODE reference proteins and, if run with RNA samples, LRP2-predicted proteins)
- `*.proteomics.reference.tsv`: Metadata table mapping protein IDs to source (GENCODE/LRP2), gene names, isoform IDs, and classification

### M2_MSCONVERT_MZML
- `*.mzML`: Mass spectrometry data in standard mzML format, converted from vendor-specific raw formats (e.g. `.raw`)

### M3_FRAGPIPE
- `peptide.tsv`: Peptide-level identifications with scores and quantification
- `combined_peptide.tsv`: Combined peptide results across runs
- `protein.tsv`: Protein-level identifications and quantification
- `psm.tsv`: Peptide-spectrum matches (PSMs) with detailed scoring
- Additional quantification and quality control files

### M4_NOVEL_PEPTIDES
- `*.peptides.bed`: Peptides mapped to genomic coordinates in BED12 format
- `*_peptide_summary.txt`: Summary table classifying peptides as annotated or novel.

## Pipeline Reports

### pipeline_info/

- `execution_report.html`: Comprehensive report including resource usage per task (CPU, memory, time), task completion statistics, and failed tasks with error messages (if any)

- `execution_timeline.html`: Interactive timeline visualization showing task start and end times, parallel execution patterns, and resource utilization over time

- `lrp2_software_versions.yml`: Complete list of software versions used in the pipeline run for full reproducibility
